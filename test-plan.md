# Test Plan — Session Manager v0.1.0

## 1. Подготовка тестового окружения

### 1.1. Тестовый репозиторий

```bash
# Создать тестовый репозиторий ВНЕ репозитория session-manager
mkdir ~/test-sm-project
cd ~/test-sm-project
git init
git config user.email "test@test.test"
git config user.name "Test"
echo "console.log('hello');" > app.js
git add . && git commit -m "initial commit"
```

### 1.2. Команда Claude

Приложение запускает `claude-sm` через `child_process.spawn`. Это shell-скрипт-враппер, который подхватывает окружение `claude-deepseek-v4` из снепшота shell-функций.

```bash
# Убедись, что враппер работает:
which claude-sm
# → /Users/k.chernyadiev/.local/bin/claude-sm

claude-sm --version
# → 2.1.62 (Claude Code)
```

Враппер находится в `~/.local/bin/claude-sm`. Если нужно использовать другую модель — отредактируй `~/.local/bin/claude-sm` (вызов функции в последней строке).

### 1.3. Изоляция

| Что | Где | Риск |
|-----|-----|------|
| Данные приложения | `~/.claude/session-manager.json` | Может перезаписать существующий |
| Логи приложения | `~/.claude/session-manager-logs/` | Только добавление |
| Сессии Claude | `~/.claude/projects/<slug>/<uuid>.jsonl` | Новые файлы по slug тестового репозитория |
| Git-ветки в тестовом проекте | `~/test-sm-project` | Создание/переключение веток |
| `.claude/` в тестовом проекте | `~/test-sm-project/.claude/` | Создаётся settings.json + hooks |

**Рекомендация:** если уже используется `~/.claude/session-manager.json` — сделай бекап перед тестом:

```bash
cp ~/.claude/session-manager.json ~/.claude/session-manager.json.bak 2>/dev/null
```

### 1.4. Сборка и запуск

```bash
cd /Users/k.chernyadiev/claus
npm run build
npm start
```

После запуска откроется окно 1200×800 с тёмной темой.

## 3. Быстрый smoke-test

Для проверки после каждого изменения — минимальный путь:

1. Запустить приложение
2. Выбрать проект `test-sm`
3. Создать Work: Description=`Smoke test`, Branch=`feature/smoke`
4. Дождаться «Needs input»
5. Нажать «Mark Complete»

Если все 5 шагов прошли без ошибок — базовый функционал работает.

## 4. Возможные проблемы и отладка

| Проблема | Куда смотреть |
|----------|--------------|
| Приложение не запускается | `npm run build` — ошибки компиляции |
| Пустой список проектов после создания | `~/.claude/session-manager.json` — проверить содержимое |
| Run не стартует | `~/.claude/session-manager-logs/<workId>.log` — stderr от Claude Code |
| Run висит бесконечно | Watchdog должен сработать через N минут, либо нажать «Stop Run» |
| Ошибка «Git не установлен» | `which git`, `git --version` |
| Ошибка spawn `claude-sm` | `which claude-sm` — скрипт должен быть в `~/.local/bin/claude-sm` |
| Error диалог не появляется | DevTools в Electron: `Cmd+Opt+I` → Console |
| Снепшот не найден | `ls ~/.claude/shell-snapshots/` — должен быть хотя бы один файл |
